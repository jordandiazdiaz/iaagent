## Calculadora

Calculadora simple en Python (sin dependencias externas).

```bash
python3 calculadora.py sumar 2 3        # 5
python3 calculadora.py restar 2 -3      # 5
python3 calculadora.py multiplicar 2 3  # 6
python3 calculadora.py dividir 1 4      # 0.25
```

Tests:

```bash
python3 -m unittest
```
