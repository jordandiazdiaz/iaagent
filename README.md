## Calculadora

Calculadora simple en Python (sin dependencias externas).

```bash
python3 calculadora.py suma 2 3            # 5
python3 calculadora.py resta 2 3           # -1
python3 calculadora.py multiplicacion 2 3  # 6
python3 calculadora.py division 1 4        # 0.25
```

Tests:

```bash
python3 -m unittest -v
```
